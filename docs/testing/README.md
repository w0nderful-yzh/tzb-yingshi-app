# 测试与评估

## 当前状态

当前已配置 Pytest，并覆盖健康检查、请求 ID、公共错误、数据库元数据契约，萤石 Token/直播地址契约、事件解析、鉴权、原文保存、去重、队列重试、媒体 PCM 切块、异步适配和乱序查询，以及防诈证据语义、S0-S5 转换、视觉语境融合、转写幂等、WAV 校验、SenseVoice 结果解析、音频块去重和 API 会话链路。

```bash
cd backend

```

## 测试层级

- 模块单元测试：规则、状态机、姿态、时序和异常处理；
- 契约测试：防诈和跌倒均能生成合法统一风险事件；
- 集成测试：API、数据库、WebSocket和外部适配器；
- Android测试：ViewModel、Repository、页面状态和断线恢复；
- 端到端测试：从测试素材或摄像头事件到Android风险展示。

## 防诈评估

- Precision、Recall、F1；
- 正常场景误报率；
- 每设备每日误报次数；
- 首次预警延迟；
- 证据链可解释率；
- 外部AI调用次数和成本。

## 跌倒评估

- 跌倒召回率和误报率；
- 正常坐卧误报率；
- 遮挡和多人场景表现；
- 从跌倒发生到事件生成的延迟；
- 连续帧事件去重效果。

## 数据要求

- 训练、验证和测试数据严格分离；
- 合成数据、公共数据和自采数据分别标记；
- 测试必须包含正常负样本；
- 不将真实老人敏感数据提交Git；
- 每次正式报告记录模型版本、阈值、数据版本和运行环境。
